Process, doors, modes

Isolation is a process. The doors are S3 and SFTP. Cache is a mode. Not shipped on DEVELOPMENT yet.

Tenant path
01
tenant gateway
One process. Its own auth. Not a shared proxy.
02
s3 and sftp
Path-style buckets and an SFTP door. Same bytes.
03
layers
Plain, optional crypt, optional chunker.
04
mode
Write-through, or write-back from a local cache.

A shared auth proxy is not tenant isolation. If the proxy dies, every tenant dies with it. storageflow keeps the failure domain on the tenant process.

Sibling products may consume the doors later. mcp-flow holds tools. OpenFlow holds workflows. This plane holds bytes.
