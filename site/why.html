Every app should not grow its own disk

A laptop folder is not a control plane. A copied object cluster is not a backend you already operate. storageflow is the front door.

Without storageflow

  • Each app keeps a private disk and a private password.
  • S3 clients and SFTP clients disagree about the same files.
  • One shared gateway means one shared failure domain.
  • Someone vendors a second object cluster to hold plain files.

With storageflow

  • S3 and SFTP see the same tenant bytes.
  • One gateway process per tenant.
  • Upstream secrets stay sealed on the plane.
  • The backing store is a remote you already run.

The bytes are files. Crypt and chunking are optional layers. Plain files sit underneath. Clients do not need the backend password.

The cluster is not here. storageflow does not vendor MinIO or another distributed object store.

S3 in these docs means the API shape. This project is not affiliated with Amazon.

Honest limits. A tenant process is not a legal warranty of isolation. CORE is the concept. The example stack is on DEVELOPMENT.
