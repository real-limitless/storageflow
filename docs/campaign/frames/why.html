The failure mode we refuse

Every app should not grow its own disk.

A laptop folder is not a control plane. A copied object cluster is not a backend you already operate.

Without storageflow

  • Each app keeps a private disk and a private password.
  • S3 and SFTP disagree about the same files.
  • One shared gateway. One shared failure domain.
  • A second object cluster holds plain files.

With storageflow

  • S3 and SFTP see the same tenant bytes.
  • One gateway process per tenant.
  • Upstream secrets stay sealed on the plane.
  • The backing store is a remote you already run.
The front door
Clients get a tenant key. They do not get the backend password.
